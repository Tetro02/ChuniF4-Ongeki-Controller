# 硬件与接线

目标为 **STM32F411CEU6，UFQFPN48，512 KiB Flash，128 KiB SRAM，外部 25 MHz HSE**。当前 PLL 为 M=25、N=192、P=2、Q=4，系统 96 MHz / USB 48 MHz。其他 F411 容量或不同晶振的板卡不能直接套用此固件。

## 输入引脚

| 名称 | 功能 | GPIO | 判定为按下 | IO4 字 / bit |
|---|---|---|---|---|
| LA | 左主键 A | PA3 | 低 | 0 / 0 |
| LB | 左主键 B | PA4 | 低 | 0 / 5 |
| LC | 左主键 C | PA5 | 低 | 0 / 4 |
| LS | 左侧键 | PB10 | **高** | 1 / 15 |
| LM | 左菜单 | PB1 | 低 | 1 / 14 |
| RA | 右主键 A | PA6 | 低 | 0 / 1 |
| RB | 右主键 B | PA7 | 低 | 1 / 0 |
| RC | 右主键 C | PB0 | 低 | 0 / 15 |
| RS | 右侧键 | PB12 | **高** | 0 / 14 |
| RM | 右菜单 | PB5 | 低 | 0 / 13 |
| Lever | 电位器滑动端 | PA0 / ADC1_IN0 | 0..4095 原始 ADC | Input byte 1..2 为校准后的 16 位位置 |

十个输入 GPIO 的内部配置均为上拉。普通八键按下接地；两个侧键的外部传感器必须提供与“高电平有效”一致的信号。侧键电气极性与游戏接口侧键位的极性由插件转换，不应再把普通按键一起取反。

RM 使用 **PB5**。原设计的 PB2 在所用板上受到 BOOT1 外部下拉影响，已弃用；以本表和 `firmware/Core/Inc/main.h` 为准。

电位器两端接板卡 **3.3 V、GND**，滑动端接 PA0，各模块共地。ADC 为 3.3 V 域，不能把 5 V 电位器输出直接接 PA0。正反接方向由三点校准自动判断。

USB FS：PA11=D−、PA12=D+；使用带数据线的 USB 线。SWD：PA13=SWDIO、PA14=SWCLK，另接 GND，按调试器要求接参考电压。板卡原有 USB / SWD 布线无需另接到按键。

没有随仓库发布 PCB、连接器顺序或完整原理图。本表是固件 GPIO 分配，不替代具体板卡的电源与封装核对。
