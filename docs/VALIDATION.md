## 已有证据

- 最新固件基于 STM32F411CEU6；两侧键 PB10 / PB12 高电平触发，其余八键低电平触发。
- Keil Arm Compiler 6.24 构建已通过；公开仓库整理后需从该仓库路径重新构建，不仅复用历史 HEX。
- 原生 C 测试覆盖三点正反向映射、中心死区、稳定平均采样、异常命令与状态。
- NOR Flash 模拟覆盖首次 / 已有记录时的写入边界中断、CRC / 标记 / 锚点损坏、重复保存免写、序号回绕、扇区轮换和部分擦除失败。
- 实际 HID 归一化 / 队列函数与实际 `IO4_Task` 函数经提取后，验证接收路由、保存通知完成后才写 Flash、取消、超时与 USB 重置。
- Python 测试覆盖报文解析、十键、线程读写、保存确认 / 超时状态及 GUI 控件启停。
- 游戏 DLL 已对全部 65536 个摇杆值验证方向、中心和端点，并检查十个独立键、组合键及无效帧。

## 实机观察

在已有 Windows 环境中，游戏安装的原配套插件曾实际读到约 1 kHz HID 数据；用户确认十键工作、游戏「入力テスト」中的摇杆值随操作变化。用户随后发现左右反向，修正版已安装并保留旧版备份。

以上不等于已完成修正版的游戏方向验收：重启后物理左 / 中 / 右及实际游玩方向的最终确认尚未记录。

## 仍需实物验收

- 真机保存后正常断电重启，确认 `loaded_at_boot` / `persisted` 及配置一致。
- 擦除期间 USB 暂停、真实供电跌落 / 看门狗条件下恢复、Flash 耐久。
- 特定板卡传感器电平、噪声、机械行程和实际接线。
- 修正后的游戏方向与游戏内行程设置。
- IAR 构建；上位机原生窗口所有交互与多种 DPI 条件。
